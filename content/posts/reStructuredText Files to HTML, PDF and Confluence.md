## Problem

I need to provide training material in different output formats.

## Solution

We are going to use `.rst` files (basically plain text) as our single source of truth and generate our desired outputs. 

```
.rst-files -> Sphinx
                |
                +---> HTML
                +-(SimplePDF)--> PDF
                +-(confluencebuilder)-> Confluence
```

### Ingredients

- [Python](https://www.python.org/)
- [Sphinx](https://www.sphinx-doc.org)
- [Sphinx-SimplePDF](https://sphinx-simplepdf.readthedocs.io/en/latest/)
- [Sphinx Confluence Builder](https://sphinxcontrib-confluencebuilder.readthedocs.io)
- [Docker](https://www.docker.com/)

### Initial Setup for Sphinx

Create a folder for your project and spin up a [virtual environment](https://docs.python.org/3/library/venv.html) for Python:

```bash
python3 -m venv venv
```

Add all needed dependencies in a [requirements.txt](https://github.com/vladmueller/lab/blob/main/sphinx-simplepdf/requirements.txt) file and install them via `pip`:

```bash
source venv/bin/activate
pip install -r requirements.txt
```

Initialise a new Sphinx documentation and **answer yes, if you are asked to split the source and build folder**: 

```bash
sphinx-quickstart
```

At this point, you should have a `source` folder containing your `.rst` files, and a `build` folder where the different output formats will be generated.

### Generate HTML

It is very simple to generate a HTML representation of your `.rst` files, just type:

```bash
make html
```

> [!TIP] Use [sphinx-autobuild](https://github.com/sphinx-doc/sphinx-autobuild) to dynamically build the html output on changes (hot reload).
> 
> Just add this target at the end of the `Makefile`:
> 
> ```
> livehtml:
>   sphinx-autobuild "$(SOURCEDIR)" "$(BUILDDIR)" $(SPHINXOPTS) $(O)
> ```  
> 
> and type: `make livehtml` 
   
### Generate a PDF

SimplePDF uses [WeasyPrint](https://weasyprint.org/) under the hood to generate a clean and good looking PDF from one single HTML file.

```
.rst files -(simplepdf builder)-> one single HTML file -(WeasyPrint)-> PDF
```

It is easy to integrate and to use in Sphinx, just type:

```bash
make simplepdf
```
